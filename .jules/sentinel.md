## 2024-04-14 - Replace yaml.load with yaml.safe_load
**Vulnerability:** Insecure deserialization via `yaml.load(..., Loader=yaml.FullLoader)` in multiple scripts handling configuration and token caching.
**Learning:** `yaml.FullLoader` allows the construction of arbitrary Python objects, which is a known vector for arbitrary code execution if the input YAML is untrusted or tampered with. Even though it's "Full" loader, it is not "Safe". The codebase duplicated this pattern across `kis_auth.py` and other scripts in multiple directories. `yaml.safe_load()` is sufficient for these files as they only contain standard types like dicts, lists, strings, and timestamps (which SafeLoader natively parses).
**Prevention:** Enforce the use of `yaml.safe_load()` for all YAML parsing unless there is a specific, well-documented need to instantiate custom Python objects. A linting rule or pre-commit hook (like `bandit` or a custom `ruff` rule if available) should be added to catch `yaml.load` usage.
