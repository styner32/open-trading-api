## 2025-01-20 - [Fix Insecure YAML Deserialization]
**Vulnerability:** Found multiple instances of `yaml.load(f, Loader=yaml.FullLoader)` being used to parse YAML configuration and token files. `yaml.load` even with `FullLoader` can be unsafe against untrusted input as it can instantiate arbitrary Python objects, leading to arbitrary code execution (insecure deserialization).
**Learning:** `yaml.load` was likely used for convenience or out of habit when reading configuration files, without realizing the potential security implications, especially if these files could be modified by a malicious actor or if the application were to process external YAML data in the future.
**Prevention:** Always use `yaml.safe_load()` instead of `yaml.load()` when parsing YAML files unless there is a very specific, well-understood need to instantiate custom Python objects, and the input source is strictly trusted. Establish a linting rule or code review checklist to catch usage of `yaml.load`.
