## 2024-05-24 - Replace unsafe yaml.load with yaml.safe_load
**Vulnerability:** Several Python modules in the repository (`kis_auth.py`, `kis_api.py`, etc.) were using `yaml.load(f, Loader=yaml.FullLoader)` to read configuration files. `yaml.FullLoader` allows instantiating arbitrary Python objects, leading to a critical insecure deserialization vulnerability.
**Learning:** `yaml.load` is generally unsafe, even with `yaml.FullLoader`, as it parses YAML tags which can be crafted to execute arbitrary code. The repository contained this vulnerability across multiple replicated files like `examples_llm/kis_auth.py`, `examples_user/kis_auth.py`, `legacy/Sample01/kis_auth.py`, and `legacy/rest/kis_api.py`.
**Prevention:** Always use `yaml.safe_load(f)` instead of `yaml.load(f, Loader=...)` when parsing YAML files unless the instantiation of arbitrary Python objects is strictly required and the input is fully trusted. I have updated all occurrences of `yaml.load` with `yaml.safe_load` across the codebase.
