## 2024-05-24 - Fix Insecure YAML Deserialization
**Vulnerability:** Found `yaml.load(f, Loader=yaml.FullLoader)` used for configuration and token files across multiple sample and legacy scripts (`examples_llm/kis_auth.py`, `examples_user/kis_auth.py`, `legacy/Sample01/kis_auth.py`, `legacy/rest/kis_api.py`, etc.). `yaml.load` even with `FullLoader` allows insecure deserialization and arbitrary code execution if an attacker can manipulate the YAML file.
**Learning:** The vulnerability existed because the developer might not have been fully aware of PyYAML's security considerations and used `Loader=yaml.FullLoader` (which is less safe) instead of the recommended `yaml.safe_load()`. The code was duplicated across several files, indicating a pattern of copy-pasting an insecure snippet.
**Prevention:** Always use `yaml.safe_load()` instead of `yaml.load()` when parsing YAML from potentially untrusted sources or for general configuration parsing where complex Python objects are not expected. Implement static analysis rules to flag usage of `yaml.load`.
